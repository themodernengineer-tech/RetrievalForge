# RetrievalForge

A hands-on journey into **Vector Databases, RAG, and AI Retrieval Infrastructure**, built progressively from first principles.

## Learning Path

```text
Embeddings & Semantic Search
        ↓
Vector Search & kNN
        ↓
FAISS
        ↓
ANN — HNSW / IVF / PQ
        ↓
Vector Databases
        ↓
RAG
        ↓
Hybrid Search & Reranking
        ↓
Multilingual Retrieval
        ↓
Retrieval Evaluation
        ↓
Production Retrieval Infrastructure
```
